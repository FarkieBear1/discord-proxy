Hardware Repair Tips and Useful Commands

Useful Technician Commands & Protocols

💻 System Audit Commands

  • Battery Report: powercfg /batteryreport /output "C:\battery_report.html"
  • System File Checker: sfc /scannow (Repairs corrupted Windows system files)
  • DISM Image Repair: DISM /Online /Cleanup-Image /RestoreHealth
  • Check Disk Utility: chkdsk C: /f /r (Scans for sector corruption and file system faults)
  • Drive SMART Health: wmic diskdrive get status or Get-PhysicalDisk in PowerShell
  • Network Socket Reset: netsh winsock reset & ipconfig /flushdns

🔋 Battery Replacement Tips

  1. Preliminary Health Audit: Verify capacity degradation and cycle counts using OS battery logs.
  2. Safe De-Energization: Power down completely, disconnect AC power, and unplug all external peripherals.
  3. ESD Isolation: Work on a grounded ESD mat and remove bottom cover fasteners.
  4. Primary Circuit Isolation: Disconnect the internal battery connector straight and parallel before touching logic board components.
  5. Residual Drain: Hold down the power button for 15 seconds after disconnecting the battery to clear capacitors.

💻 Display Assembly Tips

  1. Failure Isolation: Confirm whether fault originates in the panel matrix or eDP ribbon cable via external display test.
  2. Power Isolation: Always remove main battery power before disconnecting eDP display ribbons to avoid blowing backlight fuses.
  3. Bezel Extraction: Carefully unclip snap-fit bezels using non-marring plastic spudgers.
  4. Pre-Closure Test: Reconnect battery temporarily to verify pixel array and backlight integrity prior to final screw assembly.

💾 NVMe / Storage Upgrade Tips

  1. BitLocker Check: Always suspend BitLocker encryption or back up recovery keys before swapping drives or updating firmware.
  2. Thermal Pad Placement: Re-use or install thermal pads on M.2 heat spreaders to prevent controller throttling.
  3. Drive Extraction: Remove the retention screw at a 30-degree angle and pull straight out.
  4. Benchmark & SMART Verification: Confirm NVMe PCIe link speed and read/write health status post-install.
