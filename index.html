General Technical Protocols

System Audit & Terminal Commands

  • Battery Health Report: powercfg /batteryreport /output "C:\battery_report.html"
  • System File Repair: sfc /scannow (Scans and fixes corrupted system files)
  • DISM Image Servicing: DISM /Online /Cleanup-Image /RestoreHealth
  • Disk Error Check: chkdsk C: /f /r (Identifies sector defects and file system issues)
  • SMART Drive Health: wmic diskdrive get status or Get-PhysicalDisk in PowerShell
  • Winsock Reset: netsh winsock reset & ipconfig /flushdns

Battery Replacement Protocols

  1. Health Audit: Verify hardware capacity degradation and cycle counts using OS battery logs.
  2. Safe De-Energization: Shut down system completely, remove AC power adapter, and unplug peripherals.
  3. ESD Protection: Work on a grounded ESD anti-static mat before unfastening bottom chassis screws.
  4. Circuit Isolation: Disconnect the internal battery connector straight and parallel before touching logic board components.
  5. Residual Drain: Hold the system power button down for 15 seconds after battery detachment to deplete circuit capacitors.

Display Assembly Protocols

  1. Isolation Test: Confirm whether screen failure originates in panel matrix or eDP ribbon cable using external display output.
  2. Power Isolation: Always isolate main battery power prior to disconnecting eDP display cables to prevent blown backlight fuses.
  3. Bezel Disassembly: Unclip plastic bezels carefully using non-marring nylon pry spudgers.
  4. Pre-Closure Test: Temporarily reconnect battery to test pixel matrix and backlight integrity before final reassembly.

NVMe & Storage Replacement Protocols

  1. BitLocker Verification: Suspend BitLocker or verify recovery key availability prior to updating storage hardware.
  2. Thermal Pads: Re-apply or preserve thermal pads on M.2 metal heatsinks to avoid thermal throttling.
  3. Extraction Angle: Remove M.2 retention screw at a 30-degree angle and pull straight out from slot.
  4. Validation Checks: Confirm PCIe link speeds and check SMART status post-installation.
