HP Repair Protocols

🔑 HP Firmware & Boot Keys

  • BIOS / UEFI Setup: Tap F10 repeatedly immediately upon startup.
  • One-Time Boot Menu: Tap F9 repeatedly immediately upon powering on.
  • System Diagnostics: Tap F2 on startup to load HP PC Hardware Diagnostics UEFI.
  • BIOS Recovery (Win + B / Win + V): Hold Windows Key + B or V while powering on, then press power for 2-3 seconds to recover corrupted BIOS.

🚨 HP Caps Lock / Num Lock LED Blink Codes

Format: [Long Blinks (Power/Caps)] - [Short Blinks (Beeps)]

  • 1 Long, 1 Short: CPU not functional or missing processor.
  • 2 Long, 2 Short: BIOS corruption, CMOS failure, or block read error.
  • 3 Long, 3 Short: Memory (RAM) module error, missing, or unseated.
  • 4 Long, 4 Short: Graphics controller (GPU) failure or display initialization error.
  • 5 Long, 5 Short: System board general failure or power plane fault.

🔋 HP EliteBook / Pavilion Battery Servicing

  1. Disassembly Prep: Power down completely and disconnect all external cables. Unscrew bottom chassis captive screws.
  2. Rubber Foot Extraction: Note that many modern HP models hide screws underneath adhesive rubber strips; peel carefully using a heat gun or spudger.
  3. Logic Board Isolation: Disconnect the main battery cable from the system board connector parallel to the board.
  4. CMOS Hard Reset: If servicing bricked boards, disconnect the internal RTC coin cell / CMOS battery alongside main power for 30 seconds.
