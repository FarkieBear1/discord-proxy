Technical Reference

Windows setup / OOBE

TopicProcedure / notes
Ctrl + Shift + F3Enters Audit Mode from Windows Setup/OOBE on supported builds; system reboots. Intended for OEM deployment and preparation, not everyday sign-in.
Shift + F10Opens Command Prompt during many Windows Setup/OOBE screens; availability depends on edition, device and policy.
start ms-cxh:localonlyFrom an OOBE command prompt, may open local-account creation on some Windows 11 builds; Microsoft can change or remove this behavior.
OOBE\BYPASSNROLegacy Windows 11 setup command to restart and expose an offline setup path on some builds; removed or restricted in newer builds.
Win + R → msinfo32System Information for hardware, BIOS, OS version and drivers.

Repair and system health

TopicProcedure / notes
sfc /scannowElevated terminal: check and repair protected Windows system files.
DISM /Online /Cleanup-Image /RestoreHealthElevated terminal: repair the component store; may require Windows Update or repair source.
chkdsk C: /scanOnline scan for NTFS filesystem issues; avoid unnecessary repair writes on failing drives.
powercfg /batteryreportGenerate an HTML battery history report in the current directory.
Get-PhysicalDiskPowerShell: view storage device health and media type.

Network and device inventory

TopicProcedure / notes
ipconfig /allList network interface IP, DNS and DHCP details.
ipconfig /flushdnsClear local DNS resolver cache.
Test-NetConnection example.com -Port 443PowerShell: check TCP reachability to a service.
Get-CimInstance Win32_BIOSPowerShell: BIOS version and serial information.
Get-PnpDevice -PresentOnlyPowerShell: list currently present Plug and Play devices.

Service note: Model, firmware version and region can change key combinations and hardware options. Verify the exact device service manual and back up important data before repairs.
